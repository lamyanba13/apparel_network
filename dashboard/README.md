# Dashboard foundation

This package is the store and administrator Next.js App Router foundation for Fashion Network.

It contains only the root layout, a neutral placeholder page, strict TypeScript, TailwindCSS, ESLint, Prettier, and Vitest configuration. Authentication, store operations, administration, catalog, inventory, and reservations are intentionally absent in Phase 1.1.

From the repository root, use `corepack pnpm dev:dashboard`, `corepack pnpm lint`, `corepack pnpm typecheck`, and `corepack pnpm build`.
