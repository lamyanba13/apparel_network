# Public frontend foundation

This package is the customer-facing Next.js App Router foundation for Fashion Network.

It contains only the root layout, a neutral placeholder page, strict TypeScript, TailwindCSS, ESLint, Prettier, and Vitest configuration. Customer discovery, accounts, products, stores, and reservations are intentionally absent in Phase 1.1.

From the repository root, use `corepack pnpm dev:frontend`, `corepack pnpm lint`, `corepack pnpm typecheck`, and `corepack pnpm build`.
